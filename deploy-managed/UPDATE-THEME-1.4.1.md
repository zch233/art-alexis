# 主题 1.4.1 更新说明

仅修正首页装饰线和卡片外框，无数据库迁移，不修改作品、分类或媒体。插件保持 1.2.1。

1. 先备份线上网站和当前主题；建议先在暂存站验证。
2. WordPress → 外观 → 主题 → 添加主题 → 上传主题，选择本次 art-alexis-theme.zip。
3. 出现同名主题提示时选择“使用上传的主题替换当前主题”。不需要先删除主题。
4. 在 GoDaddy 设置中刷新缓存，浏览器 Ctrl+F5 强制刷新。
5. 检查初次进入首页、名字两侧、卡片悬浮，以及手机版菜单/详情页。

如果仍被旧版上传校验拦截，先切换到已安装的 Twenty Twenty-Five，再上传替换 Art Alexis，完成后重新启用 Art Alexis。切换期间前台会临时变化，宜在暂存站/维护时段进行。不需要删除媒体或重建内容。

需要回滚时，用备份的旧主题 ZIP 覆盖替换即可；本补丁未改数据。

作品图集：为同一件作品提供全貌、局部、不同角度等多张照片。分类用于组织作品，封面用于列表缩略图，图集用于详情展示。只上传一幅画时，不必额外填图集；图集为空会使用封面。此功能本次没有调整。
