已复现：Windows Compress-Archive 写入反斜杠条目 `art-alexis\style.css`，原验证器先转换为正斜杠，掩盖了原始 ZIP 路径错误。用户在 Linux WordPress 上报告缺少 style.css。

修复前计划：先让原始条目检查对旧包失败；改为 ZipArchive 显式创建正斜杠路径；重新生成主题与插件包；在 PHP 8.2 虚拟 Unix 文件系统内解压检查入口和每个文件，覆盖图片排除和校验值；旧包保留但停用，VPS 和业务代码不变。

自评审：两个 ZIP 都受影响，必须一起修；不能通过给线上补 style.css 来掩盖错误。无需新依赖或删除文件。真实 GoDaddy 安装仍需重试，解压验证不是全部运行功能验收。

模式：Full Test Flow（发布、数据迁移）。

范围：新增独立部署目录，保留 deploy/ 的 VPS 路径，共用主题/插件。仅本地构建，不连接客户服务器、不提交推送。

顺序：检查版本和打包边界 → 打包纯代码 → 单独打包已知四张初始作品 → PHP 8.2/8.3 语法及隔离运行验证 → ZIP 内容审计 → 交付。

自评审：不能用整库恢复覆盖托管账号、平台选项及 MU 插件；当前 Docker 未运行，初始素材不能冒充最新备份。先提供初始内容导入方法和完整迁移边界，不实现未验证的线上数据库替换。不自动修改缓存、CDN、域名或生产站点。

测试：安装包根目录/必需文件；不含图片/SQL/凭据；初始素材 SHA256；缺少素材时失败；PHP 8.2/8.3；独立 WP 环境激活及功能检查。GoDaddy CDN、SMTP、图片处理限额、实际上传和正式站同步须人工验收。
