# 插件 1.3.0：批量新增作品

入口：作品列表顶部“批量新增”，或作品侧栏“批量新增”。

1. 选择所属分类。
2. 多选图片：每批最多20张，单张最多15MB，JPG/PNG/静态WebP，实际还受主机上传限制约束。
3. 标题默认来自文件名，可逐项修改。
4. 点击“创建草稿作品”，一张图对应一件作品，不自动发布。
5. 等待完成；失败项可单独重试，成功项可打开编辑。检查后在作品列表中发布。
6. 全部成功后可点“再新增一批”。

请保持页面打开。同一页面同一项的重试有服务端去重保护；刷新或新开批次重新选择同一文件不视为原请求，可能新增作品，先检查草稿。服务器中途异常可能留下待完成草稿或媒体，不自动删除数据。

更新：先备份，在暂存站的“插件 → 安装插件 → 上传插件”上传 art-alexis-plugin.zip，选择替换当前版本。主题保持1.4.2，无需再次更新。刷新后台页面以加载新脚本。无需停用/重装或导入数据。

暂存站检查：用两张图片试建草稿，确认分类、图片、标题和重试。服务端需要MySQL/MariaDB命名锁；若主机不支持，会安全拒绝并提示无法锁定，不会无锁创建。正式站兼容性尚需此步骤确认。

回滚：上传旧插件覆盖，已经创建的草稿和媒体仍保留。测试数据只在本地，标题以 QA-bulk- 开头，未自动删除或发布。
