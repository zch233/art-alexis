# 插件1.3.1

批量新增增加“创建后直接发布”，默认不勾选。勾选后，每张图片成功上传并关联后发布；上传失败保留可重试草稿。无发布权限的账号不能勾选，服务器也会拒绝直接发布。批次开始后发布选项锁定，避免重试改变原意。

隐藏/未发布分类仍不公开，不会因批量发布自动公开分类。

先备份并在暂存站上传插件ZIP，选择替换当前插件；刷新后台页面。主题不变，无需迁移。回滚旧插件不会自动撤回已经发布的作品。

验证：默认草稿与直接发布、文件关联、发布权限拒绝、无效图拒绝、模式冲突、同ID重试、原批量草稿/断线重试回归、PHP语法与ZIP校验。线上未修改。本地测试产生QA命名作品和小色块媒体（包括直接发布测试），非线上内容。
