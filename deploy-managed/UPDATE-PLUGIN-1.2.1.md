# 作品管理插件1.2.1：后台Filter修复

只需更新art-alexis-plugin.zip，主题无需更新，不需要重导作品或恢复数据库。

根因：旧筛选GET参数aa_collection与WordPress分类文章类型公开query_var重名，数字分类ID被解释成name查询，导致已有作品筛选为空。改为独立参数aa_filter_collection，保留现有meta_query约束，不影响前端分类网址。

1. 备份当前插件文件，先在暂存站上传并替换插件，确认版本1.2.1。
2. 从左侧菜单重新点击「作品→全部作品」，不要仅刷新之前的筛选结果网址（旧网址仍带aa_collection参数）。
3. 选分类→Filter，检查该分类的作品；再选全部作品分类，检查全列表恢复。
4. 暂存验证后正式站重复更新。无需删除插件、清理媒体或改作品关联。

若安装包仍报“仅支持真实图片”，参考UPLOAD-FIX.md用SFTP先修复旧版上传校验。
若新网址已含aa_filter_collection但仍异常，请提供去除敏感信息后的完整后台网址及插件版本；不要在聊天中发送密码。

未自动更新任何线上环境。回滚只恢复更新前插件文件，不恢复数据库覆盖新作品。
