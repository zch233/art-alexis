# 主题/插件ZIP误被图片校验拦截：一次性修复

当前完整插件包为1.1.0，已包含下述修复；文中1.0.1是最初修复版本。优先按UPDATE-1.3.0.md更新完整插件。

原因：作品管理插件1.0.0将图片限制应用到了官方安装包上传。修复在插件中，不在主题中；只更新主题不会消除错误。

1. 在GoDaddy目标站点的SSH/SFTP设置获取连接信息，用SFTP连接。先操作暂存站。
2. 找到WordPress根目录下 wp-content/plugins/art-alexis/includes/media.php，下载原文件到电脑备份。
3. 把修复目录中的 includes/media.php 上传覆盖上述同名文件。不能多套一层目录，不能传到themes。不要改名、删除插件或停用插件。
4. 返回WP后台，在外观→主题→添加→上传中重新选择主题ZIP；选择替换已安装版本。
5. 验证作品图片上传仍正常，再在正式站覆盖同一个插件文件。暂存和正式是两份文件，需要分别修复。

单文件修复后插件详情可能仍显示1.0.0，这是正常的：版本头在另一个文件。也可在单文件修复后通过后台上传新插件1.0.1 ZIP并替换旧版本，或通过SFTP完整覆盖插件文件以统一版本。无需重新导入数据或图片。

如果覆盖后出现PHP错误，恢复刚才备份的原media.php；如果提示不变，确认操作的是正确站点和plugins路径，再请主机刷新PHP缓存。不要提供SFTP密码到聊天中。

本地验证：15项真实WordPress过滤器回归通过；11个PHP文件在PHP8.2语法通过；新包路径、哈希和PHP8.2解压验证通过。没有实际操作GoDaddy，因此仍需暂存验收一次真实后台安装。WordPress核心继续负责ZIP内容、安装权限及主题/插件结构校验。
