# 设计确认阶段执行计划

模式：Standard Flow。当前仅需求文档和静态设计预览，不执行权限、上传、数据库或上线实现。

## 目标
交付可审阅需求、信息架构，以及沿用客户模板的桌面/手机页面预览。

## 步骤
1. 检查客户模板和四张作品图片，保留原目录。
2. 写出已确认范围、建议默认值、上线前待确认项、验收场景。
3. 将原始模板与四张素材复制到工程 reference；预览使用独立 assets 副本和本地字体。
4. 制作首页、About、Work、分类页、详情页的响应式静态预览与评审入口。
5. 检查链接、图片、手机溢出与基本交互；记录未验证项。

## 计划审查
模板只包含首页，缺失页面属于本次设计范围。四张图是实际作品，不虚构更多作品凑数。真实上传、回收站、保护引用及权限留待 WordPress 实现。预览大图不能冒充最终手势实现。保留标题字体，避免外部样式决定布局。设计稿须确认后才进入功能开发。

docs/requirements.md、docs/page-structure.md、preview/、reference/、work/。

## 验证
静态资源请求、JS语法、1440px与390px截图、320px溢出、导航和大图打开关闭。后台与真实上传不在本阶段验证范围。

## 回退
原文件只复制不修改。所有新增内容独立存放，不批量删除文件；如需清理先列出明确路径再由用户决定。
