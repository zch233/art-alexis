# Docker 本地测试计划

Full Test Flow：本次涉及基础设施、数据库与本地账号。

目标：localhost:9401 可测试真实 PHP 8.3 + MySQL WordPress。独立 Compose 项目 art-alexis-test，独立命名卷，插件/主题只读挂载。保留原 Playground 数据，不迁移、不覆盖其他 Docker 项目。只绑定 127.0.0.1，不公开数据库端口。

步骤：生成随机本地凭据 → 启动独立数据库及 WordPress → WP-CLI 幂等安装/激活/导入 → 首页、后台登录、图片、权限检查 → 重启验证持久化。

自审：新端口避免冲突；命名卷保留上传及数据库；密码置于已忽略 work；初始化仅在未安装时执行，不重置已有用户。测试环境不用于生产。不删除任何目录或卷。

验收：Compose 配置有效、MySQL healthy、首页 200、4 个分类、客户账号能登录并受限、图片正常、重启后数据保留。失败先看本项目日志，不触碰现有容器。

回退：docker compose stop，仅停止本项目并保留数据。禁止 down -v。无需购买服务或部署外网；真实 GoDaddy 性能仍待上线验收。
