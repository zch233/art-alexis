# 主题 1.2.0：源码还原及交付检查

## 结果与范围

以用户导出的 `site-package/index.html`、`work-detail.html` 及首页引用的样式为基准，替换1.1.0的近似布局。只修改本地主题，不修改生产站、数据库、插件、用户或图片，不推送Git。

- 首页：100vh首屏，1380px内容框架，原稿标题尺寸、ABOUT右侧简介、横幅封面、作品标签及移动断点。
- 字体：补齐本地Poppins 500/600/700，保留Gasoek One及字体许可；不依赖远程字体。
- 分类详情：880px居中区域、粘性标题栏/关闭按钮、完整比例图片、More Work推荐；Current Works双栏，600px及以下单栏，其余分类单栏。
- 作品详情：同一画廊视觉，保留独立URL、所属分类返回、前后作品导航。
- 点击图片放大，点击图片下方作品名称进入独立作品详情。分类按12个作品分页，各作品的图集一起展示。
- GSAP、PhotoSwipe继续使用现有本地依赖；不引入Webflow运行时。依据可访问性和动效规则保留键盘、焦点恢复、减少动态效果与暂停后台粒子绘制。

## 对比方法与边界

导出目录通过本地只读服务器9402展示；主题在Docker WordPress9401验证。
同为900px视口高度，在390/768/1440宽度下比较首页关键区块的x/y/宽/高，以及详情头部、内容列的位置宽度。误差上限1px；实测关键首页尺寸差异为0或约0.02px的子像素舍入。

这不是全页逐像素相同的声明：后台实际作品数、标题、图集、排序、焦点和邮箱优先。源码的占位SVG、Untitled示例说明及示例邮箱不导入；图库总高度不与不同数据的示例强行比较。未提供独立About页源码，保留现有About功能。

Current Works默认依据已有slug `current-works` 采用双栏；其他分类默认单栏。主题提供 `art_alexis_collection_grid` 过滤器用于未来调整，无数据库迁移。

## 提交前评审

- 正确性：删除旧详情渲染分支，主题不再加载preview基底和alignment近似覆盖；首页与详情样式分开维护。
- 数据与安全：模板动态内容转义；新增页码读取仍仅查询公开内容；既有REST接口和权限校验不变。
- 性能：首张详情图片优先加载，其余懒加载、响应式尺寸；分类分页避免一次输出所有作品。CSS约22KB、JS约215KB（未压缩传输体积）；新增3个本地字体约455KB，按使用字重加载，可浏览器缓存。
- 维护：更新必须带上detail.php及3个新字重文件；单独替换CSS不完整。
- 限制：未操作GoDaddy生产/暂存站；平台缓存、线上插件冲突及实际手机Safari仍需暂存验收。

## 更新与回滚

只使用本轮交付的主题1.2.0更新包。先备份暂存站原主题，再更新 `wp-content/themes/art-alexis/`，清除GoDaddy缓存/CDN缓存。
若后台拦截ZIP并提示仅允许JPG/PNG/WebP，沿用SFTP上传解压后的主题文件，不改后缀绕过校验。
不要导入SQL、同步数据库、覆盖uploads/plugins/wp-config，不重新导入已有图片。验证暂存站的手机/桌面首页、详情、灯箱、返回、分页和后台保存后，再由用户更新正式站。
白屏、字体404、图库/保存异常时，恢复备份主题并清缓存；不回滚数据库。VPS部署目录原样保留。
