## 观察与自评审

当前与参考存在结构偏差：缺少两侧框线、导航不居中；首屏左右分栏而非横向标题带；标题负字距过紧；About 的标题/正文/整行链接布局不同；分类左右分栏而非大图+标题；缺少右下几何角。参考桌面首轮字体加载失败，不能用回退字体当设计依据。参考使用占位联系邮箱，不复制进真实网站。

完整页截图前必须滚动触发入场效果，否则把屏外 opacity=0 错判为图片丢失。对实际页面另外检查文字溢出、图片完整性、导航作用域、JS关闭和减少动态效果。
