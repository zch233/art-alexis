# 分类通用配置与交互复核

Full Test Flow：用户反馈核心浏览路径与多处视觉差异。

1. 复现localhost/127.0.0.1字体加载及源站hover，记录computed styles和请求错误。
2. 分类后台新增布局（单列/双列）及大图切换（开启/关闭）配置。旧分类未设置时保持原行为；显式设置优先于slug兼容回退。不批量改数据库，不删除数据。
3. 模板读取统一配置；关闭切换时图片独立打开（不能仅隐藏箭头而仍允许滑动）。分页追加继续遵循配置。沿用PhotoSwipe焦点/Escape与触屏支持。
4. 对照原CSS修正卡片边线、footer结构、箭头及hover断点。相同源字体不重新选型；短时padding动画按用户指定模板保留，不引入连续布局动画。
5. 测试新旧分类与非法输入、nonce/权限；两种host字体、390/1440布局、灯箱开关、键盘、卡片/footer普通及hover。运行既有回归与PHP检查。
6. 评审后交付新版包；不改线上、不推Git。回滚代码可保留新增meta（旧版本忽略），但旧版本会恢复slug决定布局。

方案评审：两项独立设置，避免把双栏与切换绑定；默认兼容而不是迁移全部分类。配置下沉插件，主题无插件新版时安全回退。字体修复限定同主机别名场景，保留真正CDN资源域名。
