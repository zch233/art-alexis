# 1.2.1 首页复查

用户确认异常截图来自 http://127.0.0.1:9401/。本轮不操作线上、不改客户数据库或图片。

## 原因与修改

- 有固定滚动条时，100vw比实际页面宽15px，使居中竖线偏7.5px。框线改用容器100%计算。
- CONTACT按邮箱条件输出，邮箱为空时flex只剩两列，导航移到右边。增加不可交互、aria-hidden且visibility:hidden的同尺寸占位；移动端不占位。
- 标题和副标题上的100vw横线围绕各自列中点定位，右侧断线；改为横跨页面并由hero裁切，整行底线附着hero-grid。去除副标题行多余竖线，保留手机各行分隔。
- 品牌伪元素的竖线伸出导航；给导航容器恢复源模板overflow:hidden。
- 独立浏览器未复现字体永久失败，不将截图细字体断言为确定的缓存问题。新增本地WOFF2、版本化URL、预加载，并保留TTF后备。Gasoek从1046648字节压缩为299628，逐个验证所有字体字形顺序和水平度量不变。
