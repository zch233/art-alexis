# WordPress 实现计划

设计于2026-09-10获确认。使用 Full Test Flow：涉及权限、上传、回收站和匿名可见性。

## 实现
1. 自包含内容插件：作品CPT与分类CPT（每件作品唯一关联分类），分类拥有原生回收站，同时增加公开隐藏与首页推荐；统一查询和访问控制。
2. 原生编辑表单：媒体库选择、图片批量上传进度重试、排序、封面焦点、说明；专用运营权限。媒体引用查询含回收内容，禁止误删。
3. 定制主题：将确认预览布局接入动态数据与路由；12条分页、加载更多、返回还原；PhotoSwipe大图、GSAP和Lenis本地打包。
4. 初始内容导入必须显式运行且可重复执行不产生重复；导入4件真实作品；默认不设置正式邮箱。
5. 配置本地运行环境，测试权限、隐藏/回收恢复、分页、媒体引用、安全输入、草稿及页面预览、移动端溢出、菜单、大图。
6. 生成安装包及部署说明；生产部署、真实域名、GoDaddy套餐和备份服务不自动操作。

## 审查决策
- 使用独立分类CPT替代taxonomy以获得分类回收站；运营界面仍称分类。关系保存为单一post meta，不自由多选。
- 所有公开出口共用可见性判断；关闭内容类型公开REST、搜索、feed、sitemap中的隐私漏洞，提供仅公开列表API。
- 不依赖隐藏菜单保障权限；实际写入、上传、永久删除均检查权限及nonce。
- 使用成熟PhotoSwipe实现手势与焦点，不手写复杂双指缩放。
- 使用WP原生媒体基础设施，专用上传器附加失败重试；限制单批20、单图15MB、12000px及像素总量。
- 引用保护同时覆盖图集、封面、About、回收站；不自动清理媒体。

## 验证
PHP语法检查、运行时插件激活、已授权/未授权行为、匿名隐藏直链/列表、非管理员永久删除、引用图片删除、已发布/草稿、13+作品分页、四件内容幂等导入、三宽度浏览器检查、大图/菜单/列表返回。
自动化不可覆盖的真机触控/GoDaddy性能/恢复备份，明确保留到上线验收。

## 回退
主题插件独立安装，不修改WP核心；关闭插件不删除数据。开发数据库、上传文件独立置于work。保留reference和preview。禁止批量删除任何目录或文件。
