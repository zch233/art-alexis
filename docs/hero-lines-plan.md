# 首屏线条和悬浮边框修正

Full Test Flow：用户逐帧反馈首页视觉差异。

根因检查：body::before的两条全页纵线独立于hero淡入，加载时抢先显示且贯穿标题/副标题；card背景绘制在全页线条上方，hover覆盖外边；横线宽度为shell+200vw，translate百分比基准过大，不能忠实表达视口划入。

方案：首页全页纵线从hero结束后开始；首屏添加仅位于标题区上方/下方的装饰线，跟随hero可见性；卡片自身外框绘制在内容之上，不占布局；横线收敛到100vw并保持左右错峰入场，增加竖线入场。用户源设计为准，不改字体、作品模型、图集或数据库。

验证：增加初始加载延迟/入场中/完成的计算样式及截图检查，确认初始没有独立纵线、标题侧边不贯穿、hover外框两边完整。覆盖390/1440、无JS、bundle失败回退、减少动画及菜单/灯箱回归。只transform/opacity的一次入场动效，不加滚动测量循环。

评审：保持无JS可读；reduce偏好关闭装饰动画；首屏布局几何不变，长标题仍可换行。上线仅需主题补丁，先暂存，再正式，回滚恢复旧主题文件，无数据恢复。
