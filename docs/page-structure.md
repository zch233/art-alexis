# 页面结构及状态

| 路径（正式站建议） | 内容 | 手机设计 |
|---|---|---|
| / | 品牌首屏、About简介、推荐分类、邮箱 | 大字自适应、菜单展开、单列分类 |
| /about/ | 标题、现有介绍、可选个人照片 | 单列正文；无照片时不占位冒充 |
| /work/ | 全部公开分类 | 单列图像与标题，数量可见 |
| /collection/{slug}/ | 分类介绍、作品卡片、加载更多 | 单列完整触控入口 |
| /artwork/{slug}/ | 返回分类、标题/简介、原比例图集、大图、前后作品 | 图片满内容宽度，独立大图查看 |
| 404 | 页面不可用、返回Work | 简单导航 |

## 内容与操作路径
运营：分类 → 新增作品 → 图片和简介 → 草稿预览 → 发布。
访客：首页或Work → 分类 → 作品详情 → 大图 → 关闭 → 返回分类原位置。

## 设计评审重点
1. 新页面的标题大小、留白、边框延续是否符合首页。
2. 手机列表及详情是否足够突出作品，触控入口是否明显。
3. 固定详情是否适合今后不同横竖比例作品。
4. About目前只有客户已提供的简介，个人照片留作可选字段。

## 预览说明
preview/index.html为可点击设计；preview/review.html提供桌面和手机并排评审。
