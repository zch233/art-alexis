## 差异及处理

| 项目 | 原 WordPress 前端 | 本轮处理 |
| --- | --- | --- |
| 页面外框 | 满屏铺开，缺少两侧贯穿框线 | 桌面约32px/手机12px外边距，共用内容框线，超宽屏限制内容宽度 |
| 导航 | 品牌左、所有链接挤在右侧 | 桌面导航居中；设置真实邮箱后联系入口独立居右；手机保留可键盘操作菜单 |
| 首屏 | 标题/副标题左右分栏，只有左上角装饰 | 改为整行标题带+副标题行，恢复左上与右下几何角 |
| 标题 | 负字距使字形过紧；分类也用展示字体 | ALEXIS恢复正常字距；分类改用Poppins，减少长标题拥挤 |
| About | 左标题右正文横排，链接塞在正文中 | 标题独立一行；桌面正文右半列，手机单列；底部整行链接 |
| Work | 多出说明眉题，段落间距不同 | 对齐参考的标题、分隔线和留白 |
| 分类卡片 | 桌面左图右字 | 全宽横幅+下方标题；桌面约2.7:1、手机4:3，保留后台焦点控制 |
| 图片大小选择 | 仍按半屏 sizes 选择图片 | 首页全宽使用1920级衍生图及匹配 sizes；懒加载，详情仍保留完整比例 |
| 作品入场 | 页面初始化便把所有屏外分类 opacity 置0 | 卡片默认可见，进入视口时才短动画；减少动态/JS故障不留下大片不可见内容 |
| 缓存更新 | CSS/JS以文件时间为版本 | 改用内容哈希；托管平台整页/CDN缓存仍需清理 |
| 手机无JS | 原菜单默认隐藏，JS不执行无法导航 | 无JS直接显示导航；JS可用时再启用折叠菜单 |

参考页手机首屏占用约一整屏且留白较大，本轮保留几何结构但适当缩短，便于更早看到作品。没有原样复制 Webflow 脚本/远程字体依赖，也没有改作品内容或加入示例邮箱。

参考页首轮遇到 WebFont 未定义及字体回退；重试已获取字体正常的参考截图。正式站首轮移动访问曾连接中断，重试成功。完整页截图滚动后采集，避免把未触发的旧入场效果误认成图片丢失。

## 安全更新路径

主题版本1.1.0；仅更新主题，不需要导入SQL或图片，不需要重新迁移网站。

1. 先备份暂存主题与站点，在暂存更新并验收。此轮不需要更新作品管理插件。
2. 若后台上传主题仍遇到“仅支持真实JPG/PNG/WebP”，这是此前已定位的插件全局上传校验问题，未在本次视觉调整中修改。不要反复尝试、不要改文件后缀。
3. 推荐使用暂存站专用SFTP：在电脑解压新主题ZIP，将里面 `art-alexis` 的文件覆盖到目标站 `wp-content/themes/art-alexis/`。先确认目标站点地址和备份；只更新此主题，不碰插件、uploads、wp-config.php、数据库。不要误嵌套成 `art-alexis/art-alexis/`。
4. 清平台缓存/CDN缓存，无痕窗口硬刷新。核对页面加载的新CSS/JS版本参数。
5. 验证首页/菜单/分类/作品大图后，经用户确认再在生产重复主题文件更新；不要为了主题更新同步整个数据库。若异常，恢复原主题文件并清缓存。

VPS 的 deploy/ 配置保持原样；以后部署VPS时从相同源码重新 release 即获得本轮主题。
