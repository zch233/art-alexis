# 批量新增作品

Full Test Flow：上传权限、持久化、重试幂等性。范围仅插件后台，新入口不改变单件编辑和前台。沿用 WP 原生后台按钮与表单，无新设计系统。

方案：作品列表顶部增加链接，后台独立页面，分类必选、文件最多20张、可编辑标题、缩略图、逐项状态和失败重试，顺序执行每项AJAX。默认草稿，每图一件作品，缩略图字段存附件ID、图集为空。沿用现有文件内容/尺寸/格式校验。nonce、上传和作品新建及分类编辑权限都校验。

幂等：用户ID+客户端UUID为请求键，MySQL命名锁阻止同时重复操作，草稿元数据保存键，完成后重试返回相同作品；草稿已创建但上传失败时重用草稿，已有附件则重用。不删除文件。若命名锁不可用安全报错，不退化成无锁写入。页面关闭不保留本地文件队列，提示检查草稿；不承诺跨新队列的文件内容去重。

评审：标题仅纯文本并转义；前端DOM使用textContent；分类不允许回收站/自动草稿；分类在开始后锁定；失败项标题锁定保证请求含义不变；不自动发布。可访问性用原生label/button/progress/live-region，不新增弹窗。失败后保留可恢复草稿，不自动删除。

测试：登录编辑账号，列表入口与分类选择，2图创建草稿，单独编辑标题，无图/无分类，伪造JPG/超大文件，nonce及未登录拒绝，相同key并发/顺序重试不重复，新队列可创建新作品；保存旧图集/筛选回归。PHP语法及ZIP检查。测试仅本地，测试草稿保留供检查。

发布插件1.3.0，主题不变；无需迁移，暂存验证锁支持及上传限制后正式更新。回滚旧插件包，已建草稿和媒体保留。性能：每请求一图、队列顺序；无前台负担。部署后检查失败率、空图片草稿；出错停止批次检查草稿，勿重复开队列。

实现评审：CSS显式覆盖WP .button对hidden属性的display冲突；添加手机布局；输入保持原生label、状态live区域及带名称进度条。脚本加载按后台page参数识别，避免中文菜单生成的hook名称差异。服务端try/finally释放命名锁，失败保留草稿，不删除内容。

验证：check-bulk.cjs通过双图双草稿、21张/16MB客户端拒绝、实际服务器创建后响应丢失重试返回原ID、并发/顺序请求同ID、无效分类/空标题/伪JPG/错误nonce/匿名拒绝。测试期间保留了若干QA-bulk草稿和小色块附件，未发布。已有筛选测试升级为分页计数，避免新草稿超过20条导致误判；图集保留测试改为选已发布旧作品。生产主机锁能力与限额需暂存验证。
